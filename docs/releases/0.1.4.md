# As The Crow Flies 0.1.4

- The panel starts hidden until explicitly opened and remembers Show/Hide across reloads and logins.
- Hidden panels stay hidden during startup events, profile changes, and placement changes.
- The main panel now uses the same Blizzard dialog border as QuestBrief's main search window, preserving your background color.

Use `/atcf show` or the expand/collapse key binding to open the panel, and `/atcf hide` or Hide panel in settings to hide it. Existing settings and character flight knowledge are preserved.
