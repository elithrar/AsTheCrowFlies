# As The Crow Flies 0.1.0

First stable release for World of Warcraft: Forever 1.60.1 (Interface 16001).

- Find NPCs and destinations by name, role or partial text, with category, class and profession filters.
- Compare walking and flight routes by distance or estimated time. The complete verified Forever flight graph is included; flight discovery and offered itineraries gate available routes.
- Follow compact direction guidance with a gold destination name, compass bearing, pause/resume and stop controls.
- Preview destinations on the world/zone map and minimap, with independent visibility settings.
- Customize fonts, size, scale, colors and profiles through XPIsland-style options. Drag, dock, tuck and resize the navigation panel.
- Use native game icons, including a yellow active-filter funnel and grey inactive state. Footer actions fit their labels; From/To inputs sit closer to their labels.

NPC search requires an installed QuestieDB provider supporting the Forever contract-3 API. SharedMedia fonts are optional. Ground navigation provides compass bearings rather than obstacle-avoiding paths. Walking estimates include a detour allowance; flight estimates improve with observed travel. Boats, portals and cross-continent routes are not supported. Movement and choosing flights remain manual.

Offline regression tests cover routing, addon runtime behavior, packaging and release guards. These checks do not establish native rendering, combat compatibility or real taxi-journey accuracy.

Extract the AsTheCrowFlies folder into Interface/AddOns. Reload the UI after updating an already loaded addon; restart the client for a first installation. Saved profiles and character data are preserved.
