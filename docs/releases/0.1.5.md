# As The Crow Flies 0.1.5

- Match FindAnUpgrade's window borders, dark buttons, search fields and centered dropdown labels across the navigation panel, menu and options.
- Keep selected destinations visually distinct when another row is hovered.
- Keep the navigation menu on-screen when the panel is near a screen edge.
- Scroll options on short screens while preserving readable control and text sizes.
- Abbreviate long dropdown captions without shrinking their text; full names remain available in tooltips and saved selections are preserved.

Existing profiles, panel visibility and character flight knowledge are preserved. The panel starts hidden until opened with `/atcf show` or the expand/collapse key binding, and remembers Show/Hide across reloads and logins.

Validated with 164 Lua 5.1 scenarios, 19 release guard tests and five source-package tests. One private-fixture package test is skipped. Native WoW rendering and physical input remain unverified.
